# Security Policy

## Scope

DeepSeek Time is a local status indicator. Its Codex MCP server reads local time and does not expose a network listener; Hermes and DSH adapters render local UI.

## Reporting

Do not publish credentials, local profile files, or exploitable details in a public issue. Report suspected security problems privately to the repository maintainers before public disclosure. Include the affected adapter, host version, reproduction steps, and the smallest relevant log excerpt.

Please do not include API keys, session data, personal files, or full local paths containing private information.
